## 🚀 Choose Your Deployment Model

<Tabs>
  <TabItem label="Branch A: Bare-Metal Systemd">

    ### Running Applications Directly on Host OS

    Run Node.js or Python applications natively on the host OS using Systemd user or system services.

    #### Systemd Service Unit (`/etc/systemd/system/myapp.service`)

    ```ini
    [Unit]
    Description=Bare-Metal Application Service
    After=network.target postgresql.service

    [Service]
    Type=simple
    User=adminuser
    WorkingDirectory=/opt/apps/myapp
    EnvironmentFile=/opt/apps/myapp/.env
    ExecStart=/home/adminuser/.local/share/fnm/current/bin/node dist/main.js
    Restart=always
    RestartSec=3

    [Install]
    WantedBy=multi-user.target
    ```

    Management commands:
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable --now myapp
    sudo journalctl -u myapp -f -n 100
    ```

  </TabItem>
  <TabItem label="Branch B: Fully Containerized Docker">

    ### Multi-Container Stacks with Docker Compose

    Deploy applications inside isolated Docker containers with declarative `docker-compose.yml` configurations.

    #### Multi-Service Stack Example (Headless WordPress + Node API)

    ```yaml
    version: '3.8'

    services:
      wordpress:
        image: wordpress:6-php8.2-fpm-alpine
        container_name: wp_backend
        restart: always
        environment:
          WORDPRESS_DB_HOST: db:3306
          WORDPRESS_DB_NAME: wordpress
          WORDPRESS_DB_USER: wpuser
          WORDPRESS_DB_PASSWORD_FILE: /run/secrets/db_password
        volumes:
          - wp_data:/var/www/html
        secrets:
          - db_password
        networks:
          - app_net

      db:
        image: mariadb:10.11
        container_name: wp_db
        restart: always
        environment:
          MYSQL_DATABASE: wordpress
          MYSQL_USER: wpuser
          MYSQL_PASSWORD_FILE: /run/secrets/db_password
          MYSQL_ROOT_PASSWORD_FILE: /run/secrets/root_password
        volumes:
          - db_data:/var/lib/mysql
        secrets:
          - db_password
          - root_password
        networks:
          - app_net

      web_frontend:
        build:
          context: ./frontend
          dockerfile: Dockerfile
        container_name: app_frontend
        restart: always
        ports:
          - "3000:3000"
        environment:
          - NODE_ENV=production
          - API_URL=http://wordpress:80
        networks:
          - app_net

    volumes:
      wp_data:
      db_data:

    secrets:
      db_password:
        file: ./secrets/db_password.txt
      root_password:
        file: ./secrets/root_password.txt

    networks:
      app_net:
        driver: bridge
    ```

    Commands:
    ```bash
    # Spin up stack in background
    docker compose up -d --build

    # View live logs
    docker compose logs -f --tail=50
    ```

  </TabItem>
  <TabItem label="Branch C: Hybrid Architecture">

    ### Bare-Metal Database + Containerized Web Stacks

    Run your data layer directly on bare metal for max IOPS performance, while running stateless application containers in Docker.

    ```mermaid
    graph LR
        Client[Web Client / User] --> Ingress[Caddy Reverse Proxy]
        Ingress -->|port 3000| DockerApp[Docker Container: App Frontend]
        DockerApp -->|host gateway / 172.17.0.1:5432| BareDB[(Bare-Metal PostgreSQL)]
    ```

    In `docker-compose.yml`, connect to host DB using `host.docker.internal`:

    ```yaml
    version: '3.8'

    services:
      api:
        build: .
        ports:
          - "3000:3000"
        extra_hosts:
          - "host.docker.internal:host-gateway"
        environment:
          - DATABASE_URL=postgres://appuser:securepassword@host.docker.internal:5432/appdb
    ```

  </TabItem>

## 📋 Summary Matrix of Infrastructure Branches

| Layer              | Recommended Choice                           | Primary Alternative         |
| ------------------ | -------------------------------------------- | --------------------------- |
| **01. Host OS**    | Ubuntu Server (Minimal)                      | Debian / Proxmox            |
| **02. Runtime**    | Fast Node Manager (`fnm`)                    | Python (`uv`) / Docker-only |
| **03. Ingress**    | Cloudflare DNS + Caddy                       | Nginx + Certbot             |
| **04. Data Layer** | Bare-metal PostgreSQL / Containerized DB     | MySQL / SQLite              |
| **05. Deployment** | Hybrid (Bare-metal DB + Docker Compose apps) | Pure Systemd / Pure Docker  |
