## 🛠 Choose Your Runtime Path

Select the primary runtime environment for your host services:

<Tabs>
  <TabItem label="Option A: Node.js (fnm)">

    ### Fast Node Manager (`fnm`) Setup

    `fnm` (Fast Node Manager) is a fast, Rust-based Node.js version manager.

    ```bash
    # Install fnm
    curl -fsSL https://fnm.vercel.app/install | bash

    # Load fnm in ~/.bashrc
    echo 'eval "$(fnm env --use-on-cd)"' >> ~/.bashrc
    source ~/.bashrc

    # Install LTS Node.js and pnpm
    fnm install --lts
    fnm use lts-latest
    corepack enable pnpm
    ```

    Verify installation:
    ```bash
    node -v
    pnpm -v
    ```

  </TabItem>
  <TabItem label="Option B: Python Environments">

    ### Python Virtual Environment (`venv` / `uv`) Setup

    Manage Python projects cleanly without polluting system packages.

    ```bash
    # Install Python 3 & venv support
    sudo apt update && sudo apt install -y python3 python3-venv python3-pip

    # Create project directory & venv
    mkdir -p /opt/apps/my-python-app
    cd /opt/apps/my-python-app
    python3 -m venv .venv

    # Activate virtual environment
    source .venv/bin/activate
    pip install --upgrade pip setuptools
    ```

    *(Optional)* Install `uv` for ultra-fast package management:
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```

  </TabItem>
  <TabItem label="Option C: Global System Stack">

    ### Direct System Package Installation

    Suitable for static servers or single-purpose deployment nodes.

    ```bash
    # Update system packages
    sudo apt update && sudo apt upgrade -y

    # Install build tools, curl, git, build-essential
    sudo apt install -y build-essential curl git unzip tar ca-certificates
    ```

  </TabItem>

## ⚙ Systemd Path Configuration (`fnm` & `nvm`)

A common issue on Linux servers is that **Systemd services run in a non-interactive shell** and cannot find binaries installed via version managers like `fnm` or `nvm`.

### Solution: Explicit `PATH` in Systemd Unit Files

To allow Systemd services to locate Node.js binaries installed via `fnm`, specify the full binary path in the service definition:

```ini
[Unit]
Description=My Node.js Application
After=network.target

[Service]
Type=simple
User=adminuser
WorkingDirectory=/opt/apps/my-node-app
# Add fnm node binary dir to PATH
Environment="PATH=/home/adminuser/.local/share/fnm/current/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
Environment="NODE_ENV=production"
Environment="PORT=3000"
ExecStart=/home/adminuser/.local/share/fnm/current/bin/node server.js
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Enable and start your service:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now my-node-app.service
sudo systemctl status my-node-app.service
```
